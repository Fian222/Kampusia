# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Campus administrators (ADMIN), academic staff (AKADEMIK), lecturers (DOSEN),
and students (MAHASISWA). Administrators regularly work with large tables on
desktop; the application must also remain usable on mobile.

## Product Purpose

Kampusia is a campus information system for managing academic records and
course operations. Each role receives a dashboard and actions appropriate to
its responsibilities.

## Capabilities and Constraints

Existing workflows include academic master data, semesters, class offerings,
schedules, adviser KRS review, meetings, attendance, grading, and study results.
Use Indonesian academic terminology. Preserve authoritative server values,
role authorization, routes, and workflow rules.

This dashboard redesign changes frontend presentation and navigation
accessibility only. Backend logic, database design, and academic policies
remain governed by AGENTS.md and docs/DATABASE.md.

## Product Principles

Prioritize clarity, consistent interactions, fast data entry, readable tables,
useful validation, and responsive layouts. Avoid unnecessary visual complexity.

## Evidence on Hand

Product facts come from the user's redesign brief, AGENTS.md, README.md,
docs/DATABASE.md, and the existing role-specific dashboard implementation.
